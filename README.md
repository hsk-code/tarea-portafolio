# Portafolio Digital con Juego "Número Secreto"

Portafolio web para estudiante de Ingeniería en Sistemas con juego interactivo desarrollado con HTML, CSS y JavaScript.

## 📋 Contenido

- Página principal con información académica y personal
- Juego "Número Secreto" donde hay que adivinar un número del 1 al 10
- Diseño responsive adaptable a todos los dispositivos

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Font Awesome (iconos)
- Google Fonts

## 🔍 Características principales

### Portafolio:
- Secciones: Inicio, Sobre Mí, Habilidades, Proyectos, Contacto
- Diseño responsive
- Menú de navegación adaptable
- Animaciones y efectos visuales

### Juego "Número Secreto":
- Genera número aleatorio entre 1-10
- Cuenta intentos realizados
- Da pistas si el número es mayor o menor
- Permite reiniciar el juego
- Muestra estadísticas básicas
